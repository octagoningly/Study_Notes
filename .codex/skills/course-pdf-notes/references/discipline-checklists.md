# 学科检查项

下列是补充检查项，不限制其他课程。未列出的课程仍按“定义—条件—推导—图示—例题—易错点”组织。

- **数字电路：** 检查真值表、布尔化简条件、时序图、状态转换和电路图占位。
- **MATLAB：** 使用 `matlab` 代码块；说明输入、输出、工具箱或版本前提；不虚构运行结果。
- **信号与系统：** 检查信号定义、系统性质、变换对、收敛/因果/稳定条件和图像占位。
- **量子力学：** 检查符号、态空间前提、算符定义域与对易条件、物理解释和推导边界。涉及态叠加或基底展开时，区分复系数/概率幅和概率；课件给出相对几率时写明 `|C_k|^2` 的意义。若使用“正交归一基下的测量概率和归一化条件”等课件外条件，放入 `> [!info] 主动补充`。
- **复变函数与数学物理方法：** 检查定理前提、积分路径/支路/坐标图、留数或分离变量步骤及适用条件。

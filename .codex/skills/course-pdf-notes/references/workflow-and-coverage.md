# 课件处理与覆盖核对

## 取材与范围

- 将 PDF 视为权威来源，直接读取；不要仅为阅读而转换为 PPTX 或 DOCX。
- 优先提取文字层。没有文字层、结果明显乱码或缺失时才 OCR，并在笔记或交付说明中标注 `OCR 可能存在误差`。
- 默认按单次课、章节或用户指定页码处理。范围过大时按章节或学习主题拆分，不得静默跳过内容。
- 用户没有指定文件名时沿用仓库现有命名；没有约定时使用 `课程名_章节名.md`。
- 除确实不承载学习内容的封面、目录、重复页和纯装饰元素外，任何含新知识的信息页都不能静默省略。

## 覆盖清单

开始整理前，按源页建立“课件要点—笔记位置”清单。清单至少覆盖：

- 定义、符号、假设、适用条件和步骤；
- 推导中的逻辑桥梁、关键公式和结论；
- 例题的完整题设、方法和结论；
- 表格，以及图中不能被简短文字或公式可靠替代的信息。

允许合并重复表述、重组为主题结构，但不能以标题、提纲或小结替代多个原始要点。完成后按清单逐项回查，不以“章节标题已经存在”作为已覆盖的证据。

## 深度与事实边界

- 每个定理或推导要能看出“记什么、为什么成立、何时适用”。可简写纯机械代数，但须说明其为常规化简。
- 例题保留条件、方法选择、关键步骤和带单位或物理含义的结论（若课件提供）。
- 不得臆造定义、条件、推导、数值、图意或 MATLAB 运行结果。看不清或课件缺失的信息标为 `待核对（课件 p.页码）`。
- 对易混情况，必要时加入简短对比或检查清单；这不能替代源内容本身。

## 交付前回查

确认以下事项：

- 实际内容覆盖用户指定范围，且覆盖清单已逐项核对；
- 重要结论附近有关键条件，表格、流程和对比未丢失例外或前提；
- 每道例题有完整题设和可复核过程；
- 图或插图占位紧邻其支持的解释，嵌图时附件链接有效；
- 例题以外的课件外说明已标为“主动补充”。

只有仍有事项时，才在笔记末尾加入：

```markdown
## 待处理清单

- 待核对：课件 p. …；原因：…
- 待插图：课件 p. …；建议截取：…
- 附件：需要确认保存路径或命名规则。
```

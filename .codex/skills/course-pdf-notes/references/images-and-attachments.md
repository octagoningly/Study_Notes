# 图像与附件

## 模式选择

默认使用**插图占位模式**。只有用户明确要求“嵌图”“保留原图”或“把图放进笔记”时才使用**嵌图模式**。两种模式都不为装饰性页面、重复公式或不相关配图增加图片。

### 插图占位模式

- 不复制图片，也不建立整份页面图像索引。
- 仅在电路、图像、曲线、表格、几何构造或公式排版本身承载关键意义时，渲染相应页核对。
- 在相关解释后立即写出来源、内容、用途，必要时给裁剪建议：

```markdown
> [!note] 待插图
> 来源：课件 p. 12；内容：二阶系统阶跃响应曲线；用途：比较欠阻尼、临界阻尼与过阻尼的峰值和稳定时间。
> 裁剪建议：只截曲线图区域，保留坐标轴、图例和阻尼标注。
```

### 嵌图模式

1. 先检查仓库的现有附件目录、Obsidian 附件配置、模板和命名方式，必须沿用已有规则。
2. 为整份课件建立低分辨率页面索引，并按视觉内容筛选候选页：电路、波形、曲线、框图、频谱、坐标图、路径图、表格或大面积图示。文字提示如“见图”只能辅助对应，不能取代视觉筛选。
3. 仅清晰渲染候选页并目视核对；必要时裁出单幅图，检查坐标轴、标注、连线、曲线或结构。
4. 仅在图是理解结论所必需、正文明确引用，或图承载不能由简短文字/公式准确替代的信息时嵌入。
5. 图片紧跟相关解释并注明课件页码；优先裁出单幅图，不嵌入整页截图。原有待插图块在图片实际嵌入后整块删除，并按仓库既有语法替换为附件链接；若采用 `![宽度](assets/课程/xxx.png)` 形式，常用宽度为 `200 / 300 / 400 / 450 / 500 / 600 / 650`。

若未找到附件规则且用户未指定路径，不擅自新建附件目录：保留插图占位，并在交付说明中列出待确认的路径。图意无法确定时不猜测，标为 `待核对（课件 p.页码）`。

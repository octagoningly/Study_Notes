# 课程 PDF 笔记

将大学理工科 PDF 课件或讲义整理为可复习的中文 Obsidian Markdown 笔记。课件是技术内容的权威来源；整理可以重组内容，但不能把课件压缩成只剩提纲，或把不确定内容写成事实。

## 适用范围

- 用于新建、续写、补全或统一已有课程笔记，以及对课件和笔记做覆盖核对。
- 默认按用户指定的单次课、章节或页码工作；未指定时先沿用仓库既有命名、附件与笔记结构。
- 不用于逐页转录、重制幻灯片，或脱离课件编写教材式长文。
- 编辑已有笔记时保留无关的现有内容；不要因为本 skill 的规则而重写未指定范围。

## 基本原则

1. 先确认源 PDF、处理范围、目标笔记和现有约定，再开始写入。
2. 课件中的原有的内容不应该跳过或者进行概括。只能先概括+再加原文。
3. 为处理范围建立“课件要点—笔记位置”清单，并在交付前逐项回查。定义、前提、条件、推导桥梁、结论、例题、表格和图中不可替代的信息都属于核对对象。
4. 无法可靠辨认的文字、公式或图意写成 `待核对（课件 p.页码）`；不得臆造。
5. 课件外内容只为理解当前课件服务，并清楚标明其来源边界。

## 交付要求

交付时简要说明实际处理的范围、覆盖回查结果和仍待核对/待插图事项。无未解决事项时，不要在笔记中保留空的待处理清单。

# 课程 PDF 笔记

将用户提供的课程 PDF 整理成便于复习的 Markdown 笔记。技术含义必须忠实于课件，同时提升结构、可读性和检索性。

## 课件处理

- 将 PDF 视为权威来源，直接读取；不要仅为阅读而转换成 PPTX 或 DOCX。
- 优先提取 PDF 的文字层。若无文字层、提取结果明显乱码或缺失，才改用 OCR，并在笔记或交付说明中标注 `OCR 可能存在误差`。
- 只有电路、图像、曲线、表格、几何构造或公式排版本身承载关键信息时，才渲染对应页进行核对；默认不要渲染整份 PDF。
- 按单次课、章节或用户指定页码处理。实际覆盖范围在交付时的对话中说明；除非用户明确要求，笔记正文开头不新增“覆盖范围”区块。跨多个章节或内容过大时，优先按章节或学习主题拆分；不得悄然跳过内容。
- **完整覆盖是硬性要求：** 先按源页建立“课件要点—笔记位置”清单。指定范围内所有可复习的定义、假设、条件、步骤、推导、结论、例题、表格及图中不可由文字替代的关键信息都应进入笔记；可重组或合并重复表述，但不得把多个原始要点压缩成一句概述，更不得以“提纲”“小结”代替原课件内容。
- 只有确实不承载学习内容的封面、目录、重复页或纯装饰元素可不写入；含有新知识的信息页不得静默省略。处理完成后用该清单逐项回查，而不是只凭章节标题判断已覆盖。
- 用户未指定文件名时，沿用仓库现有命名方式；若没有既有约定，使用 `课程名_章节名.md`。
- 不得臆造定义、条件、推导步骤、数值、图意或 MATLAB 输出。课件模糊或缺失的信息标记为 `待核对（课件 p.页码）`。

## 图像策略

默认使用**插图占位模式**，以降低处理开销并便于用户后续手动截图。在该模式下不建立整份页面图像索引，也不渲染整份 PDF。只有用户明确要求“嵌图”“保留原图”或“把图放进笔记”时，才切换为**嵌图模式**。

- **插图占位模式：** 不复制图片。在相关解释之后立即插入简短标注，说明课件页码、应截取的内容和图的作用；必要时说明裁剪范围，例如保留坐标轴、图例和关键标注。
- **嵌图模式：** 先检查仓库现有附件目录、Obsidian 附件配置、模板和命名约定，再建立候选图索引并渲染、核对候选图。已有规则时必须沿用；找不到规则且用户未指定路径时，不擅自新建附件目录，改保留插图占位并在交付说明中列出需要确认的路径。嵌入图片紧跟相关解释，并注明课件页码。不要嵌入装饰性页面、重复公式或整页截图。

### 嵌图判定流程

仅在嵌图模式下执行以下流程；不能只依赖文字猜测：

1. 先为整份课件生成低分辨率页面索引，并以视觉内容筛选候选页：电路、波形、曲线、框图、频谱、坐标图、路径图、表格或大面积图示。即使老师未标图号或未写“见图”，也不能跳过这一步。
2. 再用课件文字作为辅助证据：图号、图题、`见图`、`Fig.`、波形/电路/框图/路径等表述可帮助把图与正文对应，但不是候选图的必要条件。
3. 仅对候选页进行清晰渲染和视觉核对，必要时裁切出单幅图，并检查图中的坐标轴、标注、连线、曲线或结构。
4. 满足下列任一条件才嵌图：图是理解结论所必需的；正文明确引用该图；图承载了无法用简短文字或公式准确替代的信息，例如电路拓扑、时序、波形、框图、频谱、积分路径、坐标关系或实验曲线。
5. 纯文字页、可直接写出的公式、代码、装饰图标和与本节无关的配图不嵌入。
6. 对图意仍不确定的页面，不猜测；保留 `待核对（课件 p.页码）` 占位，并说明需要用户核对的图意。

占位格式：

```markdown
> [!note] 待插图
> 来源：课件 p. 12；内容：二阶系统阶跃响应曲线；用途：比较欠阻尼、临界阻尼与过阻尼的峰值和稳定时间。
> 裁剪建议：只截曲线图区域，保留坐标轴、图例和阻尼标注。
```

## 笔记结构

默认用中文输出。采用清晰、稳定的标题层级和短段落，不按幻灯片逐页复述。

- 若课件明确给出第 N 章，标题使用 `第 N 章：主题`，不添加“课程名｜”等课程名前缀；主要模块从 `N.1` 起编号，子模块使用 `N.1.1` 形式，并按相同层级连续递增。未给出章节号时，才从 `1`、`1.1` 开始编号。
- 除非用户明确要求，笔记开头不写“本节目标”。

## 语言规范

- 即使课件主要使用英文，笔记仍默认使用中文。
- 对有必要保留英文的专业术语，在全篇首次出现时写为“中文（English）”，例如“位（bits）”；同一概念后续只写“位”，不重复附英文。
- 代码、变量名、函数名、命令、公式符号、文件名和不可直译的固定缩写保留原样。若它们是重要概念，可在首次出现处补中文解释。
- 课件已给出稳定的中英文对照时，优先沿用其译法；不要为同一术语混用多个中文译名。

```markdown
# 第 N 章：主题

## N.1 核心知识

### N.1.1 概念与定义

### N.1.2 条件与结论

> [!tip] 关键提示
> …

## N.2 推导与证明

### 推导目标

### 前提与符号

### 关键步骤

## N.3 例题与典型应用

## N.4 易错点与对比

## N.5 本节小结
```

- 空的章节不保留；只有课件确有对应内容时才新增章节。
- `##` 用于主要学习模块，`###` 用于概念、定理、方法或单个例题。
- 本仓库使用 `.obsidian/snippets/course-note-layout.css` 提供课程笔记的提示块与排版。不要新增其他 CSS 类型或在 Markdown 中写行内样式。
- 固定使用以下类型：无标题的 `[!knowledge]` 用于核心知识、`[!note] 待插图`、`[!abstract] 本节小结`、`[!info] 主动补充`、`[!tip] 关键提示`、`[!warning] 易错点`。其中 `[!knowledge]` 的标题栏和图标由 CSS 隐藏；其余提示块保留中文可见标题。
- 所有直接来自课件、可供复习的核心知识都使用 `> [!knowledge]` 彩色块：包括定义、规则、条件、结论、方法步骤及知识性表格。将相邻且属于同一知识点的正文、列表和表格合并到同一个块内；表格的每一行也要保留 `>`，确保其显示在彩色块中。
- 不把章节标题、普通过渡语、例题、课后作业或待处理清单塞入“知识内容”块；例题继续使用无颜色的普通段落。
- 例题主体不使用彩色提示块。每道例题以普通加粗标签 `**[ 例题 ] 题名**` 独占一段开始；其后空一行写出**完整题设**、思路、分步过程和结论。课件只给题目、只给结论或给出的解答过短时，仍要补全可复核的推导；所有不在课件中的推导步骤必须紧随相应题目以 `> [!info] 主动补充` 明确隔开，这是例题主体不用彩色块的唯一例外。不得在例题标题末尾添加两个空格制造强制换行，也不得用普通前导空格模拟缩进。
- **正文版式：** 默认不做首行缩进。普通正文从行首开始写，段落之间只用一个空行分隔；课程笔记 CSS 仅用于无标题知识块，禁止加入任何正文缩进规则。不得使用全角空格、`&emsp;` 或普通前导空格模拟缩进；尤其不要在正文行首加入四个或更多普通空格，因为 Markdown 会将其解析为代码块，导致公式不渲染且整段灰底右移。例题标题、正文、图片和提示块之间均以空行分隔。
- 公式使用标准 LaTeX：默认不使用独立公式。只要单行公式在正常正文宽度内仍可读，即使它含多个项或有一两步等价变形，也跟在引导句后写成 `$...$`；不要仅因公式较长就改为独立公式，以减少渲染时居中产生的大块留白。仅当出现大块、连续的多步推导（通常至少三行且每行需独立阅读）、表达式无法在正文宽度内显示，或用户明确要求强调时，才使用独立公式 `$$...$$`。不得将独立公式置于普通引用块或提示块内。符号首次出现时定义，并在结论附近写明适用条件。
- 出现两个及以上对象、条件、方法、参数或结论需要并列比较时，优先使用表格、对比提示块或编号流程；推导步骤优先采用顺序化的分步结构。
- 可视化和对比表达只用于提升理解，不得为了压缩版面而删掉前提、适用范围、例外、单位或关键推导。表格容纳不下的信息，必须在表格后补充说明。
- 结构简单且可准确转写的源表格，使用 Markdown 表格；复杂表格、无法可靠转写的公式图片或图注，在插图占位模式下保留占位，在嵌图模式下按图像流程处理。任何无法可靠识别的文字或公式均标记为 `待核对（课件 p.页码）`。

## 内容深度

每个定理或推导都清楚区分**记什么**、**为什么成立**和**何时适用**。

- 保留关键推导步骤之间的逻辑桥梁，不要只堆叠公式。
- 对纯机械代数可简写，但应明确其为常规化简。
- 例题保留题设条件，说明方法选择和关键步骤，并给出带单位或物理含义的结论（如课件提供）。
- 每道源课件例题或课堂练习必须保留完整题目文字。即使课件没有给出过程，也要给出“已知／求解目标—方法选择—逐步代入或推导—结果检查—结论”的完整解答；其中课件没有明确展示的任何步骤都必须标为“主动补充”，不能伪装成课件原结论。
- 对容易混淆的情况，在结尾给出简短对比或检查清单。

### 课件外补充

- 当课件说明过于简略、缺少必要过渡，或首次出现的术语没有解释时，可以补充少量基础说明；补充只服务于理解当前课件，不能扩展成脱离课件的教材内容。
- 所有不直接来自课件的补充，必须使用下列彩色提示块并明确标注为“主动补充”；不得把补充内容写成课件原文或教师结论。

```markdown
> [!info] 主动补充
> 此处补充内容……
```

- 对补充内容没有把握、超出当前课件范围，或不同教材表述可能不同的情况，标注 `待核对（主动补充）`，或不补充。

## 常见理工科课程的补充检查项

以下仅为常见示例，不限制其他课程；未列出的课程也按“定义—条件—推导—图示—例题—易错点”组织。

- **数字电路：** 真值表、布尔化简条件、时序图、状态转换和电路图占位。
- **MATLAB：** 使用 `matlab` 代码块；说明输入、输出、工具箱或版本前提；不虚构运行结果。
- **信号与系统：** 信号定义、系统性质、变换对、收敛/因果/稳定条件和图像占位。
- **量子力学：** 符号、态空间前提、算符定义域与对易条件、物理解释和推导边界。
- **复变函数与数学物理方法：** 定理前提、积分路径/支路/坐标图、留数或分离变量步骤和适用条件。

## 用户打磨偏好（基于量子力学 / 数电 git 历史，已验证）

以下为 agent 初版（量子力学 `5e2ece6`、数电 `911a82d`）之后用户手工改动的共性，直接作为生成默认值，减少返工：

### 美观性默认值

- 开头不写 `> [!abstract] 覆盖范围 / 本节目标`；标题用 `第 N 章：主题`，模块从 `N.1 / N.1.1` 编号，不用 `课程名｜` 前缀和 `1 / 1.1` 旧编号。
- 核心知识默认包入 `> [!knowledge]`，块内用 `- ` 并列，子项再 tab 缩进；表格每行保留 `>`。例题、作业、过渡语不塞入 knowledge。
- 例题不用彩色块，用 `**[ 例题 ] 题名**` 独占一段（注意方括号内两侧空格），删 `(课件 p.X)` 页码；题后空一行再写题设。标题末尾不加双空格，不用行首空格缩进。
- 占位 `> [!note] 待插图 + 来源 / 裁剪建议` 在嵌图后删除整块，换为紧跟解释的 `![宽度](assets/课程/xxx.png)`，常用 `200 / 300 / 400 / 450 / 500 / 600 / 650` 控制版式；装饰页、重复公式不嵌。
- `> [!tip] / [!warning]` 能删则删：简单提示降为正文 `注意：`，存疑易错点移到末尾 `待处理清单`。但为保持课件原文与课件外内容的边界，所有课件外解释、推导与例题过程必须保留为 `> [!info] 主动补充`，不得降为未标注正文。
- 公式优先行内 `$...$`；仅三行以上连续推导、超宽表达式或需强调才用 `$$`，且不放入普通引用 / 提示块内。结论处可用 `> [!knowledge] **最终导出：**` 集中复述 `boxed` 结果。
- 并列结论用有序 `1. / 2.` 或 `- `，如双势阱 `V0=∞ / V0很大有限`；表格删 `首次英文 / 页码` 列。
- 正文无首行缩进，段间一空行；禁用全角空格、`&emsp;`、行首 4 空格（会变代码块导致公式不渲染）。

### 内容默认值

- 删通用铺垫：总述段、`取粒子质量为m` 首句、`X=AB+CD` 极简例、化学罐 `AB+BC+AC` 例、低有效 `POS` 变体、`恰三输入为1` 等重复例题。
- 化简结果合并一行，如 `Z=...=...+RA+RG+AG`；配用户一句话结论，如 `图b更优：级数更少`、`卡诺图上下本质上**相连**`、`每两位异或生成偶校验位`、`基态偶函数激发态奇偶交替`。
- 定理集中前置、证明集中后置并编号 `**1证明：...**`，删 `（课件 p.X）` 和 `参见曾谨言` 主语；`也就是说` 改 `注意：`。
- 补全 agent 省略的关键显式结果：谐振子外电场 `E+V0=(n+1/2)ℏω / En=...-V0 / ψn(x)=Nn exp[...]Hn(...)` 含 `Nn,α` 定义；宇称表补 `（奇函数）/（偶函数）`。
- 纠错：`psi` 缺斜杠三处 -> `\psi`，`x>0` -> `x>a`，`前两级` -> `第一级`，`门端相连` -> `导线相连`。
- 章节归位：`不同宽度势阱 + 两态叠加` 合并为 `课堂练习` 两道 `[ 例题 ]`；`不规则势垒 D~exp` 从透射系数移到 `隧穿效应`；`推导3宽/高指数近似` 改 `[ 例子 ]`；类比无图段直接删。
- 波形三例题、5 点小结、作业 `p.41:276-278第13/14/24/25/30题` 逐字保留，不扩写。

## 交付前检查

交付前确认：

- 覆盖用户指定内容，并在交付对话中说明实际覆盖范围；
- 每个重要结论附近都有关键条件；
- 若使用嵌图模式，没有失效附件链接；
- 每张图或插图占位都紧邻其支持的解释；
- 所有课件外说明都已明确标注为“主动补充”；
- 已用“课件要点—笔记位置”清单逐项核对：源课件内容没有因概括、排版或重组而遗漏；
- 每道例题都保留完整题设，并有可复核的解答过程；课件外的推导步骤均明确标为“主动补充”；
- 表格、流程和对比块保留了相应的条件、例外与关键内容；
- 结尾有可直接复习的小结，并在合适时提供对比或易错点。

仅在存在未解决事项时，在笔记末尾增加：

```markdown
## 待处理清单

- 待核对：课件 p. …；原因：…
- 待插图：课件 p. …；建议截取：…
- 附件：需要确认保存路径或命名规则。
```

没有待处理事项时，不保留空的“待处理清单”。
